# MS Revision exam simulator

Practice AB-731, AB-900, SC-500, and AI-103 from one static site. Choose an exam, then use Practice mode for immediate explanations or Exam simulation for a timed attempt and results review.

The site is in [`exam-simulator/`](exam-simulator/). Open [`exam-simulator/index.html`](exam-simulator/index.html) locally, or publish with the included [GitHub Pages workflow](.github/workflows/pages.yml). The [simulator README](exam-simulator/README.md) explains the question banks and publishing setup.

Question content is original practice material based on the linked Microsoft Learn study guides. Scores are diagnostic percentages, not predictions of Microsoft's scaled exam score.
