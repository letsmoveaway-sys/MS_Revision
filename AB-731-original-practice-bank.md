# AB-731 AI Transformation Leader — Original Practice Bank

This is an independently written practice set based on the Microsoft AB-731 skills outline dated July 22, 2026. It does not reproduce questions from ExamTopics or the live certification exam.

Official blueprint: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-731

## Questions

### Business value of generative AI

1. A retailer wants to create several natural-language product descriptions from structured catalog data. Which type of AI is the best fit?

   A. Generative AI  
   B. Clustering  
   C. Anomaly detection  
   D. Regression

2. An organization needs a chatbot to answer questions using policies that change every week. The organization wants to avoid retraining the underlying model after every policy update. What should it use?

   A. Fine-tuning only  
   B. Retrieval-augmented generation (RAG)  
   C. Image classification  
   D. Unsupervised clustering

3. A team is estimating the operating cost of a generative AI assistant. Which measurement is most directly associated with model-inference consumption?

   A. Number of database tables  
   B. Number of input and output tokens  
   C. Number of user departments  
   D. Number of training labels

4. A model confidently invents a supplier policy that does not exist. Which generative AI challenge does this demonstrate?

   A. Overfitting  
   B. Fabrication  
   C. Encryption failure  
   D. Data duplication

5. A support team wants more consistent responses from an AI assistant. Which prompt change is most likely to help?

   A. Remove all context to shorten the prompt  
   B. State the role, task, constraints, and required output format  
   C. Replace business terms with unrelated technical jargon  
   D. Ask several unrelated questions in one instruction

6. A bank wants an assistant to cite approved internal procedures when answering employees. What is the primary purpose of grounding?

   A. To make the model larger  
   B. To connect responses to relevant, authoritative information  
   C. To eliminate authentication  
   D. To convert all prompts into images

7. A company has a small, stable set of specialized examples and needs a model to consistently adopt a particular task behavior. Which approach may be appropriate after simpler prompting has been evaluated?

   A. Fine-tuning  
   B. Removing evaluation data  
   C. Disabling monitoring  
   D. Increasing user privileges

8. Which dataset characteristic most directly helps reduce systematic performance differences among demographic groups?

   A. The dataset is representative of affected users  
   B. The dataset is stored in one file  
   C. The dataset contains the longest possible records  
   D. The dataset has no documented origin

9. A manufacturer wants to predict equipment failure from historical sensor readings. Which capability is the best fit?

   A. Predictive machine learning  
   B. Text summarization  
   C. Image generation  
   D. Language translation

10. Which sequence best represents a machine-learning lifecycle?

    A. Deploy, delete data, define the problem, and stop monitoring  
    B. Define the problem, prepare data, train and evaluate, deploy, and monitor  
    C. Buy licenses, deploy, then determine the business need  
    D. Train once, deploy, and assume performance remains constant

11. An AI application accesses confidential employee documents. Which control most directly limits each user to information they are permitted to access?

    A. Role-based authorization  
    B. A longer system prompt  
    C. A larger context window  
    D. A lower model temperature

12. Which measure provides the strongest evidence that an AI initiative creates business value?

    A. The model has the greatest number of parameters  
    B. Outcomes are compared with a defined baseline and measurable business KPI  
    C. Every employee is required to use it immediately  
    D. The project uses the newest available model

### Implementation, responsible AI, and adoption

25. Which action should occur before an organization deploys AI broadly?

    A. Define governance, acceptable-use rules, ownership, and escalation paths  
    B. Give every system unrestricted data access  
    C. Remove human review from high-impact decisions  
    D. Measure success only after several years

26. What is the main purpose of an AI council?

    A. To provide cross-functional strategy, oversight, prioritization, and accountability  
    B. To write every employee prompt  
    C. To replace the security and legal teams  
    D. To approve only the most expensive models

27. An automated screening tool performs worse for people with certain disabilities. Which responsible AI principle is most directly implicated?

    A. Fairness  
    B. Scalability  
    C. Compression

28. Users cannot tell when content was generated by AI or how to challenge an outcome. Which principles most directly address this issue?

    A. Transparency and accountability  
    B. Tokenization and latency  
    C. Scalability and caching  
    D. Compression and clustering

29. A pilot is technically successful, but employees avoid the tool because they do not understand when or how to use it. What should the adoption team do next?

    A. Provide role-based training, communicate use cases, collect feedback, and support champions  
    B. Penalize every employee who has not used it

30. What is the primary role of an AI champions program?

    A. Build peer advocacy, share practical knowledge, and surface feedback within business teams  
    B. Replace formal governance  
    C. Grant unrestricted access to sensitive data

31. Which approach best supports a responsible rollout?

    A. Start with prioritized use cases, pilot with defined measures, learn, and scale in stages  
    B. Deploy every possible use case simultaneously

    A. Pay-as-you-go

## Answer key and rationales

1. **A** — Generative AI creates new natural-language content from the supplied information.
2. **B** — RAG retrieves current material at response time, avoiding frequent model retraining.
3. **B** — Input and output token volume is a common driver of model inference cost.
4. **B** — A plausible but unsupported statement is a fabrication, often called a hallucination.
5. **B** — Explicit context, constraints, and output structure improve consistency.
6. **B** — Grounding anchors responses in relevant authoritative sources.
7. **A** — Fine-tuning can specialize model behavior when prompting or grounding alone is insufficient.
8. **A** — Representative data helps reveal and reduce uneven performance across affected groups.
9. **A** — Historical labeled sensor patterns can support prediction of future failures.
10. **B** — ML requires problem definition, data work, training, evaluation, deployment, and continuing monitoring.
11. **A** — Authorization enforces which protected resources an authenticated user may access.
12. **B** — Business value is demonstrated against a baseline with outcome-oriented measures.
13. **A** — Microsoft 365 Copilot provides assistance within Microsoft 365 work experiences.
14. **A** — Copilot Studio supports building and orchestrating agents and workflows with low-code tools.
15. **A** — Microsoft Graph exposes connected Microsoft 365 organizational context subject to permissions.
16. **A** — Researcher is designed for multi-source research and synthesis.
17. **B** — Analyst is designed for analytical work over data.
18. **A** — Azure AI Search supports indexing and retrieval patterns commonly used in RAG.
19. **A** — Azure Vision capabilities analyze and extract information from images.
20. **A** — A supported existing capability is normally evaluated before undertaking a custom build.
21. **A** — Extensibility connects Copilot to organization-specific knowledge, actions, and processes.
22. **A** — Microsoft Foundry supports the enterprise AI development and operations lifecycle.
23. **A** — Model selection should be a requirements-based tradeoff, not a size or branding contest.
24. **A** — Integration can preserve established identity, data-permission, compliance, and security boundaries.
25. **A** — Clear rules, decision rights, and escalation paths are foundations of governed adoption.
26. **A** — An AI council aligns multiple functions around strategy, risk, priorities, and accountability.
27. **A** — Unequal performance across demographic groups is primarily a fairness concern.
28. **A** — Transparency helps people understand AI use; accountability establishes ownership and recourse.
29. **A** — Role-specific enablement and feedback address practical adoption barriers.
30. **A** — Champions help colleagues learn, normalize useful practices, and relay frontline feedback.
31. **A** — A measured pilot-and-scale approach improves learning and limits unmanaged risk.
32. **A** — Pay-as-you-go is appropriate when consumption varies and cost should follow use.
